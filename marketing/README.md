# Public demo and launch copy

`linkedin-post.txt` is a draft for review, not a published LinkedIn post. The approximately 500-screenshot figure was provided by the Heyou team. No two-day productivity claim is made.

The video is a recording of the real app using an isolated, signed-out Chrome profile and these public pages:

- https://github.com/microsoft/vscode/pull/347612
- https://github.com/microsoft/vscode/pull/347605

Only the app window is recorded. Its previews and captures show those public PRs. Notifications are disabled in the demo Chrome profile; local capture history is isolated. The demo does not imply Microsoft endorsement.

To reproduce on Windows with two monitors: install `imageio-ffmpeg` in addition to the app requirements and run `python marketing/record_demo.py` from the repository root. It creates `marketing/heyou-capture-demo.mp4`; the MP4 and temporary browser profile are excluded from Git. Review the complete video before posting externally.

The clip uses captions and no microphone/audio recording. Live counters reflect files actually saved by the app. The time-saved figure shown in the app is explicitly an estimate, not a measured work-saving claim.
